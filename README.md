# YES Lab 新成员任务[](url)](url)](url)

## 环境
- Ubuntu 20.04.6 LTS
- ROS Noetic (rosversion -d 输出: noetic)
- 虚拟机: VirtualBox 7.2.18

## 安装步骤
1. 安装 VirtualBox 并创建 Ubuntu 20.04 虚拟机。
2. 运行鱼香ROS一键安装脚本，选择华为镜像源（解决官方源404问题）。
3. 成功安装 ROS1 Noetic 桌面版，并用键盘控制小海龟。

## 遇到的问题及解决办法
1. ROS官方源及国内源全部404报错。
   - 原因：官方已关闭Ubuntu 20.04的在线源。
   - 解决：使用鱼香ROS脚本，选择华为镜像源，绕过失效路径。
2. wget下载脚本时输入法报错。
   - 解决：切换输入法为英文，或去掉 -O 参数直接下载。
